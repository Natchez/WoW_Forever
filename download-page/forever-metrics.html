Installing an addon

  1. Close World of Warcraft.
  2. Open your AddOns folder, for example World of Warcraft\_forever_\Interface\AddOns
  3. Unzip the download there, so you get AddOns\ForeverMetrics\ForeverMetrics.toc (or AddOns\ForeverBuffs\…). Replace an older folder of the same name if there is one; saved data is kept.
  4. Start the game. /fm opens Forever Metrics (its window title shows the version); /fb controls Forever Buffs.
Duo mode and handy commands
/fm duo
See your partner and whether they're online
/fm duo add Name
Send a pairing request if the popup didn't show
/fm levelup check
What skill data the level-up pop-up can see
/fm debug
Show errors in chat if something isn't working
Update these stats

Log out (or /reload), then send Claude WTF\Account\<ACCOUNT>\SavedVariables\ForeverMetrics.lua from your WoW folder. Each player has their own file.
