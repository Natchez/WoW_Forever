Forever Metrics

Stats, an activity feed and loot luck for every character, plus duo mode so you two can see each other's levels, rare finds and a head-to-head scoreboard. New in this version: a redesigned window with a dashboard, a level-up pop-up that lists your new trainer skills, floating gold and loot text, and optional helpers like auto-repair and selling greys.

Install

  1. Close World of Warcraft.
  2. Open your AddOns folder. It's inside your WoW install, for example World of Warcraft\_classic_\Interface\AddOns Use whichever game folder you actually play from.
  3. Unzip the download there. You should end up with a ForeverMetrics folder directly inside AddOns, not a folder inside a folder.
  4. If an older ForeverMetrics folder is already there, replace it. Your saved stats live elsewhere and stay put.
  5. Launch the game and type /fm to open it.

Get updates with one click

The updater downloads the newest version of our addons and swaps out the old folders for you. Set it up once on each PC (Windows only).

  1. Download the updater and unzip it anywhere you'll find it again, like your Documents folder.
  2. Double-click Update WoW Addons.bat. The first time, it finds your AddOns folder (or asks you to pick it) and remembers it.
  3. Run it again whenever there's an update. If WoW is open, type /reload afterwards.

Pair up for duo mode

Log in while you're both in the guild or grouped. A popup asks whether to add the other person as your duo partner. Click Add partner once on each side and you're linked, alts included.

/fm duo
See your partner and whether they're online
/fm duo add Name
Send a pairing request if the popup didn't show
/fm duo name Nickname
Give your partner a nickname
/fm debug
Show errors in chat if something isn't working
