ForeverMetrics addon

Version 0.14.1

  1. Close World of Warcraft.
  2. Open your AddOns folder, for example World of Warcraft\_forever_\Interface\AddOns
  3. Unzip the download there, so you get AddOns\ForeverMetrics\ForeverMetrics.toc. Replace an older ForeverMetrics folder if there is one; saved stats are kept.
  4. Start the game and type /fm. The window title shows the version.
Duo mode and handy commands
/fm duo
See your partner and whether they're online
/fm duo add Name
Send a pairing request if the popup didn't show
/fm levelup check
What skill data the level-up pop-up can see
/fm debug
Show errors in chat if something isn't working
